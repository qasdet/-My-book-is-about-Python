# Последовательности в Python

## Списки (list)

### Описание
Списки - это упорядоченные изменяемые последовательности, которые могут содержать элементы разных типов.

### Создание списков
```python
# Пустой список
list1 = []
list2 = list()

# Список с элементами
numbers = [1, 2, 3, 4, 5]
mixed = [1, "text", 3.14, True]

# Создание из других последовательностей
list_from_string = list("Python")
list_from_range = list(range(5))
```

### Основные операции
```python
# Индексация и срезы
list1 = [1, 2, 3, 4, 5]
list1[0]      # 1 (первый элемент)
list1[-1]     # 5 (последний элемент)
list1[1:4]    # [2, 3, 4]
list1[::2]    # [1, 3, 5]

# Изменение элементов
list1[0] = 10
list1[1:3] = [20, 30]

# Операции со списками
list1 + list2  # Конкатенация
list1 * 2      # Повторение
len(list1)     # Длина списка
```

### Методы списков
```python
# Добавление элементов
list1.append(6)        # Добавление в конец
list1.insert(0, 0)    # Вставка по индексу
list1.extend([7, 8])  # Расширение другим списком

# Удаление элементов
list1.remove(3)       # Удаление по значению
list1.pop()          # Удаление и возврат последнего элемента
list1.pop(0)         # Удаление и возврат по индексу
del list1[1]         # Удаление по индексу
list1.clear()        # Очистка списка

# Поиск и подсчет
list1.index(3)       # Индекс первого вхождения
list1.count(2)       # Количество вхождений

# Сортировка и порядок
list1.sort()         # Сортировка по возрастанию
list1.sort(reverse=True)  # Сортировка по убыванию
list1.reverse()      # Обращение порядка элементов
```

## Кортежи (tuple)

### Описание
Кортежи - это неизменяемые упорядоченные последовательности. Они похожи на списки, но не могут быть изменены после создания.

### Создание кортежей
```python
# Пустой кортеж
tuple1 = ()
tuple2 = tuple()

# Кортеж с элементами
numbers = (1, 2, 3)
mixed = (1, "text", 3.14)

# Кортеж из одного элемента
single = (1,)  # Обязательна запятая!

# Создание из других последовательностей
tuple_from_list = tuple([1, 2, 3])
```

### Операции с кортежами
```python
# Индексация и срезы (как у списков)
tuple1 = (1, 2, 3, 4, 5)
tuple1[0]     # 1
tuple1[-1]    # 5
tuple1[1:4]   # (2, 3, 4)

# Конкатенация и повторение
tuple1 + (6, 7)  # Новый кортеж
tuple1 * 2       # Повторение

# Методы
len(tuple1)        # Длина
tuple1.count(2)    # Количество вхождений
tuple1.index(3)    # Индекс элемента
```

## Диапазоны (range)

### Описание
range - это неизменяемая последовательность чисел, часто используемая в циклах for.

### Создание диапазонов
```python
# range(stop)
range(5)      # 0, 1, 2, 3, 4

# range(start, stop)
range(2, 5)   # 2, 3, 4

# range(start, stop, step)
range(0, 10, 2)  # 0, 2, 4, 6, 8
range(5, 0, -1)  # 5, 4, 3, 2, 1
```

### Использование
```python
# В циклах for
for i in range(5):
    print(i)

# Преобразование в список
list(range(5))  # [0, 1, 2, 3, 4]

# Проверка на вхождение
3 in range(5)  # True
```

## Общие операции для последовательностей

```python
# Длина
len(sequence)

# Минимум и максимум
min(sequence)
max(sequence)

# Сумма (для числовых последовательностей)
sum(sequence)

# Сортировка (возвращает новый список)
sorted(sequence)
sorted(sequence, reverse=True)

# Проверка на вхождение
item in sequence
item not in sequence
```

## Распространенные ошибки и их решения

1. Изменение кортежа:
```python
# Неправильно
tuple1 = (1, 2, 3)
tuple1[0] = 4  # TypeError

# Правильно (создание нового кортежа)
tuple1 = (4,) + tuple1[1:]
```

2. Создание списка копированием ссылок:
```python
# Неправильно (shallow copy)
list1 = [[0]] * 3  # [[0], [0], [0]]
list1[0][0] = 1    # [[1], [1], [1]]

# Правильно
list1 = [[] for _ in range(3)]
```

3. Изменение списка при итерации:
```python
# Неправильно
for item in list1:
    if condition:
        list1.remove(item)  # Может пропустить элементы

# Правильно
list1 = [item for item in list1 if not condition]
```

## Советы по эффективному использованию

1. Используйте кортежи вместо списков для неизменяемых данных
2. Применяйте list comprehension вместо циклов for там, где это возможно
3. Используйте range вместо создания временных списков в циклах
4. При частом доступе по индексу используйте список, при частом поиске - множество
5. Для больших наборов данных используйте генераторы вместо списков
