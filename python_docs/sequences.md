# Коллекции в Python: списки, кортежи и диапазоны

## Списки (list) - универсальные хранилища

### Что такое список?
Список в Python - это как чемодан, в который можно сложить что угодно: числа, тексты, другие списки. И в отличие от реального чемодана, в Python-список можно добавлять и убирать вещи в любой момент!

### Создаём списки
```python
# Пустой список - как новый чемодан
покупки = []
дела = list()

# Список с элементами - уже собранный чемодан
цифры = [1, 2, 3, 4, 5]
разное = [42, "привет", 3.14, True]  # Можно хранить разные типы

# Создаём из других вещей
буквы = list("Python")  # ['P', 'y', 't', 'h', 'o', 'n']
счётчик = list(range(5))  # [0, 1, 2, 3, 4]
```

### Что можно делать со списками?
```python
# Находим нужные элементы (как вещи в чемодане)
вещи = ["книга", "ручка", "ноутбук", "зарядка"]
первая = вещи[0]      # "книга"
последняя = вещи[-1]  # "зарядка"
две_вещи = вещи[1:3]  # ["ручка", "ноутбук"]

# Меняем содержимое
вещи[0] = "планшет"  # Заменяем книгу на планшет
вещи[1:3] = ["карандаш", "тетрадь"]  # Заменяем несколько вещей

# Объединяем списки
одежда = ["футболка", "джинсы"]
все_вещи = вещи + одежда  # Объединяем два списка
много_одежды = одежда * 2  # Дублируем список
```

### Полезные методы списков
```python
# Добавляем вещи
вещи.append("наушники")      # В конец списка
вещи.insert(0, "телефон")   # В начало списка
вещи.extend(["мышка", "коврик"])  # Добавляем несколько

# Убираем вещи
вещи.remove("наушники")  # Убираем по названию
старая_вещь = вещи.pop()  # Убираем и запоминаем последнюю вещь
вещи.clear()  # Убираем всё

# Ищем и сортируем
номер = вещи.index("телефон")  # Где лежит телефон?
есть_ли = "ноутбук" in вещи    # Проверяем наличие
вещи.sort()  # Сортируем по алфавиту
вещи.reverse()  # Переворачиваем список
```

## Кортежи (tuple) - неизменяемые списки

### Что такое кортеж?
Кортеж - это как список, но который нельзя изменить после создания. Как запечатанная посылка - что положили, то и дойдёт до получателя!

### Создаём кортежи
```python
# Пустой кортеж
пустой = ()
ещё_пустой = tuple()

# С элементами
координаты = (10, 20)
результат = ("успех", 100, True)

# Особый случай - кортеж из одного элемента
один = (42,)  # Запятая обязательна!
```

### Работаем с кортежами
```python
# Получаем элементы
точка = (10, 20, 30)
x = точка[0]  # 10
y = точка[1]  # 20

# Распаковка - очень удобная штука!
x, y, z = точка  # Раскладываем по переменным

# Объединение
точка_а = (1, 2)
точка_б = (3, 4)
линия = точка_а + точка_б  # (1, 2, 3, 4)
```

## Диапазоны (range) - умные последовательности

### Что такое range?
Range - это как волшебный счётчик. Вместо того чтобы хранить все числа, он помнит только правило их создания. Очень экономно!

### Создаём диапазоны
```python
# От 0 до N-1
пять = range(5)  # 0, 1, 2, 3, 4

# От A до B-1
от_до = range(2, 6)  # 2, 3, 4, 5

# От A до B-1 с шагом C
чётные = range(0, 10, 2)  # 0, 2, 4, 6, 8
обратный = range(10, 0, -1)  # 10, 9, 8, ..., 1
```

### Используем диапазоны
```python
# В циклах
for i in range(5):
    print(f"Шаг {i}")

# Создаём списки
список = list(range(3))  # [0, 1, 2]

# Проверяем числа
5 in range(10)  # True
12 in range(10)  # False
```
