# Путешествие по типам данных Python

Привет, друзья! Давайте вместе исследуем удивительный мир типов данных в Python. Здесь вы найдёте всё, что нужно знать о строительных блоках ваших программ - от простых чисел до сложных структур данных.

## В нашем путешествии мы посетим:

1. [Числа и математику](numeric_types.md)
   - Целые числа (int) - ваши верные помощники в подсчётах
   - Дробные числа (float) - когда точность имеет значение
   - Комплексные числа (complex) - для тех, кто мыслит многомерно

2. [Текстовый мир](strings.md)
   - Создание текста - от простого к сложному
   - Волшебные методы работы со строками
   - Искусство форматирования
   - Магия срезов

3. [Коллекции и последовательности](sequences.md)
   - Списки (list) - универсальные хранилища данных
   - Кортежи (tuple) - неизменные защитники ваших данных
   - Диапазоны (range) - генераторы последовательностей

4. [Словари - ваши умные помощники](dictionaries.md)
   - Как создать личный справочник
   - Магия работы с ключами и значениями
   - Полезные приёмы и хитрости

5. [Множества - математика в действии](sets.md)
   - Множества (set) - когда порядок не важен
   - Неизменяемые множества (frozenset) - гарантия стабильности
   - Операции из школьной математики

6. [Логика и пустота](boolean_none.md)
   - Булевы значения (bool) - искусство принятия решений
   - Тайны значения None
   - Секреты сравнения

7. [Мир байтов и памяти](binary_types.md)
   - Байты (bytes) - цифровые строительные блоки
   - Изменяемые байты (bytearray) - гибкая работа с данными
   - Представления памяти (memoryview) - взгляд изнутри

## Особенности нашего мира

- В Python всё является объектом - от простого числа до сложной структуры
- Каждый тип данных обладает своими суперспособностями (методами и атрибутами)
- Python сам заботится о типах данных (динамическая типизация)
- Легко превращать один тип в другой (когда это имеет смысл)
