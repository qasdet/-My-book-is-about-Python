# Числовые типы данных в Python

## Целые числа (int)

### Описание
Целые числа в Python представляют собой числа без дробной части. В Python 3 тип `int` не имеет ограничений по размеру (кроме доступной памяти).

### Создание
```python
# Прямое присваивание
x = 42

# Через преобразование
y = int("42")
z = int(3.14)  # Округление до целого числа

# Различные системы счисления
bin_num = 0b1010  # Двоичная (10)
oct_num = 0o10    # Восьмеричная (8)
hex_num = 0x1F    # Шестнадцатеричная (31)
```

### Операции
```python
# Арифметические операции
x + y    # Сложение
x - y    # Вычитание
x * y    # Умножение
x / y    # Деление (результат всегда float)
x // y   # Целочисленное деление
x % y    # Остаток от деления
x ** y   # Возведение в степень

# Побитовые операции
x & y    # AND
x | y    # OR
x ^ y    # XOR
~x       # NOT
x << y   # Сдвиг влево
x >> y   # Сдвиг вправо
```

## Числа с плавающей точкой (float)

### Описание
Числа с плавающей точкой представляют действительные числа в Python. Они реализованы с использованием двойной точности (64 бита).

### Создание
```python
# Прямое присваивание
x = 3.14
y = 2.0

# Научная нотация
z = 1e-10  # 1 × 10^(-10)

# Через преобразование
f = float("3.14")
g = float(42)  # 42.0
```

### Особенности и ограничения
- Ограниченная точность (примерно 15-17 значащих цифр)
- Возможны ошибки округления
- Специальные значения: `float('inf')`, `float('-inf')`, `float('nan')`

```python
# Пример проблем с точностью
0.1 + 0.2 != 0.3  # True
round(0.1 + 0.2, 1) == 0.3  # True

# Работа с бесконечностью
inf = float('inf')
x = inf + 100  # inf
y = inf - inf  # nan
```

## Комплексные числа (complex)

### Описание
Комплексные числа состоят из действительной и мнимой части, где мнимая часть обозначается суффиксом 'j'.

### Создание
```python
# Прямое присваивание
z1 = 2 + 3j
z2 = complex(2, 3)  # То же самое

# Получение частей числа
real = z1.real  # 2.0
imag = z1.imag  # 3.0
```

### Операции
```python
# Основные операции
z1 + z2    # Сложение
z1 - z2    # Вычитание
z1 * z2    # Умножение
z1 / z2    # Деление
abs(z1)    # Модуль комплексного числа
z1.conjugate()  # Комплексно-сопряженное число
```

## Преобразование между числовыми типами

```python
# int → float
float(42)  # 42.0

# float → int
int(3.14)  # 3 (округление в сторону нуля)

# int/float → complex
complex(1)     # 1+0j
complex(1, 2)  # 1+2j
```

## Полезные функции для работы с числами

```python
# Встроенные функции
abs(-5)      # Абсолютное значение
round(3.14, 1)  # Округление
pow(2, 3)    # Возведение в степень

# Из модуля math
import math

math.floor(3.7)   # 3 (округление вниз)
math.ceil(3.2)    # 4 (округление вверх)
math.trunc(3.7)   # 3 (отбрасывание дробной части)
math.sqrt(16)     # 4.0 (квадратный корень)
```

## Распространенные ошибки и их решения

1. Деление на ноль:
```python
try:
    result = 1 / 0
except ZeroDivisionError:
    print("Деление на ноль недопустимо")
```

2. Проблемы с точностью float:
```python
from decimal import Decimal

# Вместо
0.1 + 0.2  # 0.30000000000000004

# Использовать
Decimal('0.1') + Decimal('0.2')  # Decimal('0.3')
```

3. Преобразование строк в числа:
```python
try:
    num = int("не число")
except ValueError:
    print("Невозможно преобразовать строку в число")
```
