# Магия чисел в Python

## Целые числа (int) - ваши верные счётчики

### Знакомьтесь - целые числа!
Целые числа - это как счётчики в реальной жизни. Хотите посчитать количество яблок, этажей в доме или баллы в игре? Целые числа - то, что нужно! В Python они могут быть любыми - хоть миллион миллионов (память компьютера - единственный предел).

### Как создать целое число?
```python
# Самый простой способ
яблоки = 42

# Превращаем текст в число
этажи = int("5")
очки = int(3.9)  # Округлится до 3

# Продвинутая магия - числа в разных системах счисления
двоичное = 0b1010    # Это число 10 в двоичной системе
восьмеричное = 0o10  # Это число 8 в восьмеричной системе
шестнадцатеричное = 0x1F  # Это число 31 в шестнадцатеричной системе
```

### Что можно делать с числами?
```python
# Обычная арифметика - как в школе!
x + y    # Сложение (2 + 2 = 4)
x - y    # Вычитание (10 - 5 = 5)
x * y    # Умножение (3 * 3 = 9)
x / y    # Деление (получится float, 10 / 3 = 3.333...)
x // y   # Целочисленное деление (10 // 3 = 3)
x % y    # Остаток (10 % 3 = 1)
x ** y   # Возведение в степень (2 ** 3 = 8)

# Продвинутая магия - побитовые операции
x & y    # Побитовое AND (как пересечение множеств)
x | y    # Побитовое OR (как объединение множеств)
x ^ y    # Исключающее OR (только уникальные биты)
~x       # Инверсия (все биты наоборот)
x << y   # Сдвиг влево (умножение на 2 в степени y)
x >> y   # Сдвиг вправо (деление на 2 в степени y)
```

## Дробные числа (float) - когда важна точность

### Что такое float?
Числа с плавающей точкой - это как линейка с миллиметрами. Когда нужна точность (например, рассчитать стоимость покупки или измерить температуру), float приходит на помощь.

### Создаём дробные числа
```python
# Просто пишем с точкой
температура = 36.6
цена = 19.99

# Научная нотация для больших и маленьких чисел
скорость_света = 3e8  # 300 000 000 м/с
размер_атома = 1e-10  # 0.0000000001 м

# Превращаем другие типы в float
вес = float("73.5")
приближение_пи = float(22) / 7
```

### Особенности работы с float
```python
# Будьте осторожны с точностью!
0.1 + 0.2 != 0.3  # Правда! (из-за особенностей хранения)
print(0.1 + 0.2)  # 0.30000000000000004

# Как с этим работать?
from decimal import Decimal  # Для точных денежных расчётов
цена1 = Decimal('0.1')
цена2 = Decimal('0.2')
print(цена1 + цена2)  # Ровно 0.3
```

## Комплексные числа (complex) - для продвинутых вычислений

### Когда они нужны?
Комплексные числа - как координаты на плоскости. Они незаменимы в физике, электронике и сложных расчётах, где одного измерения недостаточно.

### Как с ними работать?
```python
# Создание комплексных чисел
z1 = 3 + 4j      # Где 3 - реальная часть, 4 - мнимая
z2 = complex(1, 2)  # То же самое через функцию

# Получение частей числа
print(z1.real)   # 3.0 (реальная часть)
print(z1.imag)   # 4.0 (мнимая часть)

# Основные операции
z3 = z1 + z2     # Сложение комплексных чисел
z4 = z1 * z2     # Умножение
abs(z1)          # Модуль комплексного числа (5.0)
```

## Советы по работе с числами

1. Используйте `int` для подсчёта предметов и простых вычислений
2. Применяйте `float` когда нужна точность, но помните о погрешностях
3. Для денежных расчётов лучше использовать `Decimal`
4. Комплексные числа пригодятся в научных расчётах
5. Не бойтесь экспериментировать - Python не даст вам сломать числа! 😉
