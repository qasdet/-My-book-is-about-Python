## Первые шаги с pytest
Познакомьтесь с pytest - вашим надёжным помощником в тестировании Python-кода. Он прост в освоении, но богат возможностями, которые сделают ваше тестирование эффективным и приятным.

## Как начать работу
Начнём с простого - установки pytest:
```bash
pip install pytest
```

## Настраиваем pytest под себя
Файл pytest.ini - это ваш личный пульт управления pytest. Давайте настроим его под ваши нужды:

```ini
[pytest]
# Где искать тесты?
test_files = test_*.py *_test.py

# Метки для удобной группировки тестов
markers =
    медленный: отмечаем долгие тесты (пропустить: '-m "not медленный"')
    интеграционный: тесты интеграции компонентов

# Как запускать?
addopts = -v --tb=short

# Что пропускать при поиске?
norecursedirs = .* venv dist build

# Как выводить результаты?
console_output_style = progress

# Сколько ждать выполнения?
timeout = 300
```

## Фикстуры: ваши верные помощники
Фикстуры - это умные помощники, которые подготовят всё необходимое для ваших тестов:

```python
import pytest

@pytest.fixture(scope="session")
def подключение_к_бд():
    # Открываем дверь в базу данных
    соединение = создать_соединение()
    yield соединение
    # Аккуратно закрываем за собой
    соединение.close()

@pytest.fixture(scope="function")
def тестовые_данные():
    # Готовим свежие данные
    данные = {"тест": "значение"}
    yield данные
    # Убираем за собой
    данные.clear()

def test_база_данных(подключение_к_бд, тестовые_данные):
    assert подключение_к_бд.is_connected()
    assert тестовые_данные["тест"] == "значение"
```

## Хуки: расширяем возможности
Хуки - это ваши возможности вмешаться в работу pytest на разных этапах:

```python
# conftest.py
def pytest_configure(config):
    """Настраиваемся перед стартом"""
    config.addinivalue_line("markers", "медленный: пометка для медленных тестов")

def pytest_collection_modifyitems(session, config, items):
    """Корректируем список тестов"""
    for item in items:
        if "медленный" in item.keywords:
            item.add_marker(pytest.mark.skip(reason="пропускаем медленные тесты"))

def pytest_runtest_setup(item):
    """Подготовка перед каждым тестом"""
    print(f"Готовим тест: {item.name}")
```

## Параметризация: тестируем разные сценарии
Один тест - много проверок. Звучит эффективно? Так и есть:

```python
import pytest

@pytest.mark.parametrize("вход,ожидание", [
    ("привет", 6),
    ("мир", 3),
    ("", 0)
])
def test_длина_строки(вход, ожидание):
    assert len(вход) == ожидание

# Комбинируем параметры
@pytest.mark.parametrize("x", [1, 2])
@pytest.mark.parametrize("y", [3, 4])
def test_умножение(x, y):
    print(f"{x} * {y} = {x * y}")
```

## Маркеры: организуем тесты
Маркеры помогут вам управлять тестами как дирижёр оркестром:

```python
import pytest

@pytest.mark.медленный
def test_долгая_операция():
    # что-то требующее времени
    pass

@pytest.mark.skip(reason="пока не готово")
def test_будущая_фича():
    pass

@pytest.mark.xfail(strict=True)
def test_ожидаемая_ошибка():
    assert False

@pytest.mark.dependency(depends=["test_a"])
def test_b():
    pass
```

### 2. Умные фикстуры
```python
# conftest.py
import pytest

@pytest.fixture(scope="session")
def конфигурация_приложения():
    return {
        "url_базы_данных": "postgresql://localhost/test",
        "ключ_api": "тестовый_ключ"
    }

@pytest.fixture(scope="function", autouse=True)
def настройка_логирования():
    # Включаем логи перед тестом
    yield
    # Чистим логи после теста
```

### 3. Ускоряем тестирование

```ini
[pytest]
# Запускаем тесты параллельно

```

### 4. Обработка ошибок
```python
def test_обработка_исключений():
    with pytest.raises(ValueError) as info_исключения:
        raise ValueError("тестовая ошибка")
    assert str(info_исключения.value) == "тестовая ошибка"

@pytest.mark.xfail(raises=ZeroDivisionError)
def test_деление_на_ноль():
    1 / 0
```

### 5. Работа с временными файлами
```python
def test_с_временной_директорией(tmpdir):
    # tmpdir - встроенная фикстура pytest
    путь_к_файлу = tmpdir.join("тест.txt")
    путь_к_файлу.write("тестовое содержимое")
    assert путь_к_файлу.read() == "тестовое содержимое"
```

### Полезные приёмы

1. **Проверяем, что выводится в консоль:**
```python
def test_вывод(capsys):
    print("привет")
    вывод = capsys.readouterr()
    assert вывод.out == "привет\n"
```

2. **Пропускаем тест при определённых условиях:**
```python
import sys

@pytest.mark.skipif(sys.version_info < (3, 7),
                    reason="нужен python 3.7 или выше")
def test_новая_функция():
    pass
```

3. **Улучшаем сравнение:**
```python
@pytest.mark.assertrepr_compare(op='==')
def assert_подробное_сравнение(op, левое, правое):
    return ["Детальное сравнение:",
            f"Слева: {левое}",
            f"Справа: {правое}"]
```

4. **Создаём тесты динамически:**
```python
def pytest_generate_tests(metafunc):
    if "параметр" in metafunc.fixturenames:
        metafunc.parametrize("параметр",
                           [1, 2, 3])
```

5. **Анализируем производительность:**
```ini
# pytest.ini
[pytest]
addopts = --durations=10 --durations-min=1.0
```

Это руководство поможет вам освоить pytest и сделать ваше тестирование более эффективным и приятным. Используйте эти приёмы и рекомендации для создания надёжных и понятных тестов.
